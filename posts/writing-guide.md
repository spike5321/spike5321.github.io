这篇本身就是一个排版样例。写新文章时如果忘了某个语法怎么写，回来翻一下就行。

## 标题

用 `#` 开头，几个 `#` 就是几级标题。文章里建议从二级标题 `##` 开始用，因为一级标题会自动取自 `index.json` 里的 title。

出现三个以上的二级标题时，文章顶部会自动生成目录。

## 文字强调

**加粗**用两个星号，*斜体*用一个星号，~~删除线~~用两个波浪号，`行内代码`用反引号包起来。

## 列表

无序列表：

- 第一项
- 第二项
  - 可以缩进两个空格来嵌套
  - 再来一条
- 第三项

有序列表：

1. 先做这个
2. 再做那个
3. 最后收尾

任务清单：

- [x] 已经完成的事
- [ ] 还没做的事

## 引用

> 引用别人的话，或者想要强调的一段，用大于号开头。
> 连续多行会合并成一段。

## 代码块

用三个反引号包住，后面写语言名就有高亮：

```python
def greet(name):
    """打个招呼"""
    if not name:
        return "Hello, stranger"
    return f"Hello, {name}!"

print(greet("world"))
```

```js
const posts = await fetch("posts/index.json").then(r => r.json());
posts.sort((a, b) => b.date.localeCompare(a.date));
console.log(`共 ${posts.length} 篇文章`);
```

支持的语言：`js` `python` `css` `html` `bash` `json`，写别的语言也能正常显示，只是没有配色。

## 表格

| 写法 | 效果 | 备注 |
| --- | --- | --- |
| `**文字**` | **加粗** | 最常用 |
| `[名字](链接)` | 超链接 | 外部链接会自动新窗口打开 |
| `![](图片路径)` | 插入图片 | 图片放 `images/` 文件夹 |

## 链接和图片

普通链接这样写：[GitHub Pages 官方文档](https://docs.github.com/pages)。直接贴网址也会自动变成链接。

插入图片：把图片文件放进 `images/` 文件夹，然后写 `![图片说明](images/文件名.jpg)`。

## 分割线

三个连字符单独一行：

---

## 新文章的两步

1. 在 `posts/` 里新建一个 `.md` 文件，比如 `my-idea.md`，直接开始写正文（不用写一级标题）；
2. 打开 `posts/index.json`，照着已有的格式加一段：

```json
{
  "slug": "my-idea",
  "title": "文章标题",
  "date": "2026-08-01",
  "summary": "一句话摘要，会显示在首页列表里。",
  "tags": ["随笔"]
}
```

`slug` 必须和文件名一致（不含 `.md`）。想先存草稿不公开，加一行 `"draft": true` 即可。
