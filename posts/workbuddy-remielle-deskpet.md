给 WorkBuddy 写了个桌面宠物（桌宠）。它不是单纯待着好看——它会"偷看" AI 正在干什么，然后切换动画：思考问题的时候歪头托腮，跑工具的时候埋头画画，回复完成就得意地叉腰。

## 核心思路：一条单向链路

桌宠能感知状态，靠的是一条很简单的链路：

```text
WorkBuddy 事件 → Hook 记录 → 本地状态中枢 → 桌宠播放器
```

WorkBuddy 在运行时会发出各种事件（收到消息、调用工具、等待确认、回复完成）。一个 Hook 脚本把这些事件悄悄记下来；本地跑着一个"状态中枢"小程序，负责把事件翻译成状态；桌宠播放器每 250 毫秒问一次状态中枢"现在是什么状态"，然后播放对应的动画。

三者各干各的，任何一环出问题都不会影响 WorkBuddy 本身。

## 它怎么判断"在做什么"

状态中枢把事件翻译成 9 种状态：待机、思考、工作中、长时间工作、深度工作、等待确认、完成、等待、出错。关键是几条规则：

- 工具开始和结束事件按"会话 + 工具名"配对，防止计数错乱；
- 冷启动时不回放历史事件，不会一开机就乱动；
- "完成"动画只播一次，不会因为状态保持几秒而重复播放。

## 一点游戏彩蛋：绝区零版状态名

既然形象来自绝区零，顺手把九种状态翻译成游戏里的说法：

| 桌宠状态 | 绝区零风格说法 |
| --- | --- |
| 待机 idle | 在六分街闲逛 |
| 思考 thinking | 解析空洞数据 |
| 工作中 working | 执行委托 |
| 长时间工作 working_long | 长线委托进行中 |
| 深度工作 deep | 深入空洞核心 |
| 等待确认 awaiting | 等绳匠做决定 |
| 完成 done | 委托完成，报酬到手 |
| 等待 waiting | 在绳网待机 |
| 出错 error | 遭遇以骸！ |
