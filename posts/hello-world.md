开这个站的理由很简单：想有一个不被平台规则左右的地方，把想到的东西写下来，并且十年后还能打开。

## 为什么不用现成的平台

微信公众号、知乎、各种笔记应用都很好用，但它们有两个共同的问题：内容的排版和去留最终不由自己决定，而且很难整体导出。写在自己的网站上，文章就是一个个纯文本文件，放在自己的硬盘和 GitHub 仓库里，随时可以搬走。

## 这个网站是怎么做的

没有复杂的框架，就是最朴素的三样东西：

- **HTML / CSS / JavaScript** 各一份，负责长什么样
- **Markdown 文件** 一篇文章一个，负责写什么
- **GitHub Pages** 免费托管，负责让别人能访问

没有构建步骤，没有依赖包，不需要装 Node.js。改完文件推送上去，一分钟后网站就更新了。

> 选技术方案的时候，我优先考虑的不是功能多，而是五年后还能不能顺利打开、顺利修改。

## 接下来打算写什么

大概是这几类：

1. 做项目过程中的踩坑记录
2. 读到的好东西和一点自己的想法
3. 一些没什么用但有意思的折腾

如果你也在想搭一个自己的小站，我的建议是：**先发出第一篇，再慢慢改样式**。样式可以永远调下去，但内容不写就永远是零。
