你好，我是 Spike。

这里是我写字的地方。取名叫「信号与噪音」，是因为我觉得生活里大部分信息都是噪音——刷过的信息流、忘掉的标题、重复了一遍又一遍的观点。偶尔有那么几条，像是信号，值得记下来。

## 我在做什么

目前主要在折腾代码和各种技术工具，偶尔写点东西。这个网站本身就是一次折腾的产物——没有用现成的博客平台，而是从零搭了一个纯静态的小站，所有文章就是一个个 Markdown 文件，放在自己的硬盘和 GitHub 上。

感兴趣的方向：前后端开发、效率工具、把复杂的事情做简单。

## 这个网站

- 每篇文章都是认真写的，不追热点，不凑字数
- 更新频率不固定，有想法了就发
- 没有评论区，想聊就发邮件，最靠谱
